# This Endoscopy Does Not Exist

A public demonstration of 50 synthetic endoscopy images from an unconditional StyleGAN2 model trained from scratch at 512×512. The assessed checkpoint achieved FID 4.95. Refresh or use **New image** to browse saved synthetic samples; the public site does not perform live GPU inference.

All displayed files are generated images, not source patient photographs. The code repository contains no model weights, training images, participant identities, or internal review files. Generated PNGs are distributed as a separate release asset and remain out of Git.

Frontend adapted from the project’s static gallery. StyleGAN2 implementation: https://github.com/NVlabs/stylegan2-ada-pytorch . The original NVIDIA code and license remain upstream; model code and weights are not redistributed here.
